# FuraFila

Agendamento de serviços públicos sem esforço: o usuário diz o serviço, pedimos
só o que ele exige e agendamos por ele.

- [Fluxo de interação](docs/interacao.md): canal web, produtos (agendamento
  gratuito + modo caçador pago) e etapas.
- [Catálogo de serviços](catalogo/): passaporte e Poupatempo (CIN).
